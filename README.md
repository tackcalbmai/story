# story

Cinematic birthday gift: interactive web short + motion-comic language.

## Run
Static HTML/CSS/JS. No build step.

Cloudflare Pages: framework `None`, build command empty, output directory `/`.

## Optional personal audio
When available, add:
- `assets/audio/winter.mp3` — «Вечная зима»
- `assets/audio/love-voice.m4a` — short original voice-note fragment with the first «люблю»

The story works without them and falls back to a procedural soundscape.

## Directing/debug mode
Open with `?debug=1` to reveal scene/time controls.

## Privacy
The page is `noindex`, but the repository is currently public. Before adding private audio, make the repo private if you do not want the source/materials publicly accessible.
