# Между станциями

Мобильный workprint реалистической интерактивной истории. Текущая версия проверяет один законченный игровой фрагмент:

`посадка → сумка → найденный диктофон → STOP/REW/PLAY → звуковая реконструкция → совпадение голоса`.

## Принципы

- одна постоянная геометрия вагона;
- звук несёт улику, но имеет нейтральные субтитры;
- игрок действует с предметами, а не листает слайды;
- Украина и Латвия обозначены только странами;
- никаких фантастических правил, адресов, городов и номеров маршрута;
- safety-first: следующий сюжетный шаг ведёт к проводнице и 112 до полной разгадки.

## Статус

Это проверочная первая сцена, не финальная игра. Визуальные материалы и голоса временные до утверждения storyboard и animatic.
